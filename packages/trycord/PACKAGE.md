# Trycord — native .light hosting package

Source: `/home/ultim/trycord/.trycord` (git `e33733b`), imported 2026-11-21.
Package version: 1.0.0 · App version: 7.2.0 · Node: 22 (Debian bookworm slim).

## Layout
- `src/` — production application files copied from upstream (backend src + scripts,
  frontend static client, public site, manifests). `node_modules`, `.git`, `.env`,
  databases and caches were deliberately excluded.
- `scripts-src/` — backend operational scripts (migrate, backup, restore, etc.).
- `Dockerfile` — multi-stage, non-root (`node`), tini PID 1, port 9971,
  `/api/health` healthcheck, persistent `/data` + `/app/uploads`.

## Runtime
- Single container serves the web client, public site, REST API and WS gateway on 9971.
- SQLite at `/data/trycord.db`; uploads at `/app/uploads` — both survive recreation.
- Required env: `JWT_SECRET` (auto-generated by .light per service).
- Mail defaults to `MAIL_MODE=log` (safe; no credentials).
- Voice subsystem is a separate process (`node src/voice/index.js`, UDP 3478)
  and is not enabled by default in the hosting package.

## Update procedure
1. Pull new upstream source into `/home/ultim/trycord/.trycord`.
2. Copy production files into `src/` and `scripts-src/` (exclude node_modules/.git/.env/*.db).
3. Bump package version here, rebuild image, roll out explicitly.
4. Customer data in `/data` and `/app/uploads` is preserved; no automatic overwrite.

## Registration
Registered as package `trycord` with product `trycord` in the .light registry.
Provisioning uses the standard Shade `instance.create` pipeline with this image.
